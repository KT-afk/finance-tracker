# The Finance Tracker Book

This book tells the story of how we build the finance tracker. It is written in simple English. Short sentences. One idea at a time.

Anyone can read it: the owner, a new helper, or an AI agent starting a new session.

## Chapters

1. [How we work](01-how-we-work.md): tickets, tests, reviews and the backlog.
2. [The finance agent](02-the-finance-agent.md): what we built, ticket by ticket.
3. [Lessons](03-lessons.md): mistakes, surprises and how to avoid them.
4. [Where we are](04-where-we-are.md): the hand-over note. Start here when picking the work up.

## How to keep this book

- After each ticket, add a short section to chapter 2.
- When something surprises you or goes wrong, add it to chapter 3.
- When the way we work changes, update chapter 1.
- At the end of each working session, update chapter 4.
- Write in simple English. Explain any word a newcomer may not know.
- Say what happened, even when it was a mistake.
