# Suggest Project Improvements

Use this slash command to get evidence-based improvement recommendations for your project.

## What it does

- Analyzes your project's intended function and current capabilities
- Generates improvement candidates across multiple impact areas:
  - Functional completeness and consistency
  - Product/API fit and developer experience
  - Reliability and error handling
  - Security and privacy
  - Observability and operations
  - Performance and scalability
  - Maintainability and code quality
  - UX/UI improvements (when applicable)
- Validates each recommendation with concrete evidence
- Prioritizes recommendations by impact and effort
- Groups suggestions into quick wins, larger investments, and risks

## When to use

- When you want to improve your project but aren't sure where to start
- Before planning a new development cycle or sprint
- When seeking to enhance reliability, security, or performance
- To identify technical debt and maintainability issues
- For comprehensive improvement planning
- When you need evidence-based recommendations rather than generic advice

## Usage

Type `/improve` in your chat to start the improvement analysis process.

The improvement analysis will:
1. Define your project's intended function and constraints
2. Establish current capabilities and identify gaps
3. Generate improvement candidates across all impact areas
4. Validate each candidate with source code evidence
5. Prioritize recommendations by impact and effort
6. Return organized suggestions with implementation strategies
