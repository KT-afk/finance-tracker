# Redesign

Audit-first upgrade of an existing website or app to premium quality without breaking functionality. Identifies generic/AI tells, applies taste and system rules surgically, and delivers comprehensive improvements while maintaining all existing features.

## What it does

- Performs comprehensive UI/UX audit of existing interfaces
- Identifies generic patterns, AI-generated content, and design inconsistencies
- Applies surgical improvements using design system principles
- Maintains 100% functional compatibility during upgrades
- Enhances accessibility, performance, and visual quality
- Implements modern interaction patterns and micro-animations

## When to use

- When your UI looks generic or lacks professional polish
- To upgrade from MVP/prototype to production quality
- When experiencing inconsistent design patterns
- For accessibility and usability improvements
- Before major product launches or redesigns
- When users report confusing or outdated interfaces

## Usage

Type `/redesign` in your chat to start the audit-first redesign process.

The system will:
1. **Audit Phase**: Analyze existing UI for issues and opportunities
2. **Strategy Phase**: Define improvement priorities and design direction
3. **Implementation Phase**: Apply surgical upgrades without breaking functionality
4. **Validation Phase**: Ensure improvements work across all scenarios

## Audit Categories

### Visual Quality
- Typography hierarchy and readability
- Color usage and contrast ratios
- Spacing consistency and visual rhythm
- Icon usage and visual clarity

### Interaction Design
- Button states and feedback
- Form validation and error handling
- Navigation patterns and information architecture
- Loading states and progress indicators

### Accessibility
- Screen reader compatibility
- Keyboard navigation
- Focus management
- Color contrast and visual accessibility

### Performance
- Loading optimization
- Animation performance
- Responsive behavior
- Cross-browser compatibility

## Output includes

- **Audit report** with prioritized issues and opportunities
- **Before/after comparisons** showing specific improvements
- **Implementation plan** with step-by-step changes
- **Code updates** for enhanced components
- **Accessibility improvements** with WCAG compliance
- **Performance optimizations** for better user experience
