# Project Audit

Use this slash command to perform an exhaustive functional and UI bug audit for your project.

## What it does

- Builds a complete inventory of all project surfaces (routes, endpoints, components, functions)
- Creates a coverage ledger tracking what was checked
- Systematically inspects behavior against intended functionality
- Exercises the system through tests and real browser automation
- Identifies bugs in functional, contract, validation, integration, data, UI, and test categories
- Provides detailed findings with file references and fix strategies

## When to use

- When you want to review every function, page, route, endpoint, workflow, or feature for bugs
- Before major releases or deployments
- When experiencing unexplained issues
- To verify the project works as intended
- For comprehensive quality assurance

## Usage

Type `/audit` in your chat to start the project audit process.

The audit will:
1. Define intended behavior from documentation and tests
2. Build a complete surface inventory
3. Create and maintain a coverage ledger
4. Inspect behavior systematically
5. Exercise the system through tests
6. Report findings with severity rankings and evidence
