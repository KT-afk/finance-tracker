# Design Code

Generate production-ready, accessible, token-driven component code for ANY framework (React, Next.js, SwiftUI, Vue, Svelte, React Native, Flutter, Jetpack Compose, Web Components, or CSS-in-JS). Uses the Adapter Protocol to ensure framework-agnostic output with built-in accessibility and design system compliance.

## What it does

- Generates component code for any framework using design tokens
- Ensures 100% accessibility compliance (WCAG 2.2 AA/AAA)
- Applies design system patterns and component anatomy
- Includes all 8 component states (default, hover, focus, active, disabled, loading, error, success)
- Implements proper focus management and keyboard navigation
- Follows framework-specific best practices and patterns

## When to use

- When building new UI components from scratch
- To implement design system components in code
- When creating accessible, production-ready components
- For rapid prototyping with production-quality output
- When migrating components between frameworks
- To ensure accessibility compliance from the start

## Usage

Type `/design-code` in your chat to start component generation.

The system will:
1. Analyze your requirements and target framework
2. Apply design tokens and component anatomy principles
3. Generate accessible markup with proper ARIA attributes
4. Include all interactive states and transitions
5. Add focus management and keyboard navigation
6. Output framework-specific, production-ready code

## Supported Frameworks

- **Web**: React, Next.js, Vue, Svelte, Web Components, Lit
- **Mobile**: React Native, Flutter, SwiftUI, Jetpack Compose
- **Styling**: Tailwind CSS, CSS-in-JS, Styled Components, Emotion
