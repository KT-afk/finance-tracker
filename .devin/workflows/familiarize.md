# Familiarize Project

Use this slash command to build a comprehensive understanding of your codebase architecture and functionality.

## What it does

- Reads repository instructions, documentation, and build files
- Maps modules, source roots, test areas, and project structure
- Identifies entrypoints, boundaries, and external dependencies
- Traces core user flows from entrypoint through the system
- Understands data models, contracts, and API specifications
- Verifies build and test commands
- Synthesizes a concise project brief with evidence-backed insights

## When to use

- When joining a new project or codebase
- Before making changes to unfamiliar code
- To understand project architecture and module boundaries
- When you need to trace how specific features work
- To identify high-risk areas and likely change points
- For comprehensive project onboarding

## Usage

Type `/familiarize` in your chat to start the project familiarization process.

The familiarization will:
1. Establish project intent and purpose from documentation
2. Inventory the repository structure and technology stack
3. Find entrypoints and system boundaries
4. Trace representative core flows
5. Understand data models and contracts
6. Verify build/test reality
7. Provide a concise project brief with key insights
